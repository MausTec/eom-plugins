# Brainfuck

Maus-Tec JSON Plugin stress-test. Runs a brainfuck interpreter on `modeSet` using a hardcoded
program that computes 42 (`++++++++[>+++++<-]>++.`) and logs the result.

Why do we need brainfuck? Because why not.

Exercises the full loop, branch, and byte-array path in mt-actions. The `log` output
will show integer `42` followed by `brainfuck: done` if everything worked correctly.

Abso-brain-fucking-lutely NOT intended for production use.
